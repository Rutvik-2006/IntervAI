# IntervAI - React Frontend

This is the frontend client for the **IntervAI** application, built using React, Vite, and Tailwind CSS.

For full project setup instructions (including running the backend and database), please refer to the **[Root README](../README.md)**.

## 🚀 Quick Start (Frontend Only)

Make sure you have installed the project dependencies:
```bash
npm install
```

Start the Vite development server:
```bash
npm run dev
```

Build the application for production:
```bash
npm run build
```

---

## 🛠️ Scripts & Tools

* **`npm run dev`**: Launches the local development server at [http://localhost:5173](http://localhost:5173) with Hot Module Replacement (HMR).
* **`npm run build`**: Compiles production-ready, optimized static files to the `dist` directory.
* **`npm run lint`**: Runs fast linting checks via `oxlint`.
* **`npm run preview`**: Runs a local web server to preview the production build.
